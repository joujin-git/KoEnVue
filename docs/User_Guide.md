# KoEnVue 사용 설명서

Windows 한/영 입력 상태를 화면에 띄워주는 플로팅 인디케이터입니다.

- **한** — 한글 입력 모드
- **En** — 영문 입력 모드
- **EN** — 한국어 외 다른 IME (일본어 / 중국어 등)

CAPS LOCK이 켜져 있으면 라벨 **둘레에 연보라색 테두리**가 함께 나타나, 한/영 상태와 CAPS LOCK 상태를 동시에 확인할 수 있습니다 (꺼지면 테두리도 자동으로 사라집니다). 보라색은 CAPS LOCK 전용 색이라 한/영 색과 헷갈리지 않으며, **상세 설정 → 공통 — 색상 → CapsLock 색**에서 바꿀 수 있습니다 (커서 헤일로의 CAPS LOCK 표시도 같은 색).

---

## 실행 방법

1. `KoEnVue.exe`를 원하는 폴더에 두고 더블클릭하면 끝납니다.
2. 시스템 트레이(작업 표시줄 우측)에 아이콘이 나타나고, 화면에 작은 인디케이터가 표시됩니다.
3. 첫 실행 시 `koenvue_config.json`이 같은 폴더에 자동으로 만들어집니다.

> v0.9.3.0 부터 관리자 권한이 필요 없습니다 — UAC 동의 창 없이 바로 실행됩니다.
> `Program Files` 처럼 사용자 쓰기 불가 위치에 두면 `koenvue_config.json` 과 `koenvue.log` 가 `%LOCALAPPDATA%\KoEnVue\` 로 자동 이동합니다.
> .NET 런타임 설치는 필요 없습니다 — 단일 실행파일입니다.
> v0.9.4.0 부터 관리자 권한 cmd / 관리자 Windows Terminal 의 한/영 상태를 보려면 트레이 메뉴 **"관리자 권한으로 실행"** 을 켜세요 (선택, 기본 OFF — 자세한 내용은 아래 트레이 메뉴 절).

## 인디케이터 사용법

| 동작 | 설명 |
|------|------|
| **좌클릭 (짧은 클릭)** | 인디를 **일시 숨김**. 그 자리 마우스 클릭이 아래 창으로 통과합니다. 다른 창으로 포커스를 바꾸거나 한/영을 바꾸면 다시 표시. 트레이「한/영 배지 숨김」(`user_hidden`)과는 별개 — 재시작 후에도 유지되지 않음 |
| **드래그** | 인디를 마우스로 끌어 원하는 위치에 배치 (시스템 드래그 임계를 넘기면 이동으로 인식). 상세 설정 / 위치 기록 정리 창이 열려 있는 동안에는 잠깁니다 — 열어 둔 채 옮기면 그 위치가 저장됐다가 「확인」 을 누를 때 되돌아가기 때문 |
| **앱별 위치 기억** | 앱마다 마지막에 둔 위치를 자동으로 기억 |
| **자석 스냅** | 드래그 중 다른 창 가장자리에 자석처럼 달라붙음 |
| **Shift + 드래그** | Shift를 누른 채 드래그하면 가로/세로 한 방향으로만 이동 |
| **드래그 활성 키 (선택)** | 드래그 **승격** 게이트. 기본(없음)은 임계 초과 시 항상 드래그. 트레이에서 Ctrl/Alt/Ctrl+Alt 를 고르면 해당 키를 누른 채 끌 때만 드래그. 짧은 클릭은 항상 일시 숨김 |

> 멀티 모니터 / 고해상도(DPI) / 화면 회전 모두 자동으로 대응합니다.

## 트레이 아이콘 조작

| 조작 | 동작 |
|------|------|
| **좌클릭** | 누를 때마다 **네 가지 상태를 차례로 돕니다** — ① 둘 다 보임 → ② 배지만 → ③ 헤일로만 → ④ 모두 숨김 → 다시 ①. 지금 상태가 어디든 그 다음으로 넘어갑니다. 트레이 아이콘이 곧 현재 상태입니다 — 아이콘은 **바깥 흰 안개 고리(커서 헤일로) + 안쪽 사각형(한/영 배지)** 모양이고, **보이는 것만 그려집니다**. ① 고리+사각형 → ② 사각형만 → ③ 고리만 → ④ 아무 도형도 없음. 넷이 모두 다르게 보이므로 아이콘만 봐도 지금 무엇이 켜져 있는지 알 수 있습니다. ④단계에서도 **배경색으로 한/영 상태는 계속 보입니다**. 이 상태는 `koenvue_config.json` 에 저장돼 앱을 다시 켜도 유지됩니다. **상세 설정 → 일반 — 트레이 → "좌클릭 동작"** 에서 `설정 파일 열기` (메모장으로 `koenvue_config.json` 열기) 또는 `동작 없음` 으로 바꿀 수 있으며, 그 경우 숨김 해제는 아래 우클릭 메뉴의 **"한/영 배지 숨김"** 항목으로 합니다 |
| **우클릭** | 트레이 메뉴 열기 (아래 참고) |

| 항목 | 설명 |
|------|------|
| **KoEnVue v… — GitHub** (헤더) | 항상 메뉴 맨 위에 굵은 글씨로 보이는 헤더 라인. 평소엔 현재 실행 중인 버전을 표기하고, 클릭하면 [GitHub 레포](https://github.com/joujin-git/KoEnVue) 가 기본 브라우저에서 열립니다 (이슈 신고·최신 릴리스·라이선스 확인 등). 앱 실행 시 GitHub 에 새 릴리스가 있으면 라벨이 자동으로 `KoEnVue v{지금 버전} → v{새 버전} — 다운로드` 로 바뀌고, 이때 클릭하면 다운로드 페이지(특정 릴리스 페이지)가 열립니다. (자동 업데이트는 아니며, 새 exe 를 직접 내려받아 교체해야 합니다.) 새 버전 확인 자체를 끄려면 **상세 설정 → 일반 → "부팅 시 업데이트 확인"** 체크 해제 (또는 `koenvue_config.json` 에서 `update_check_enabled: false`) |
| **한/영 배지 숨김** | 최상위 — 한/영 배지 **한 가지만** 켜고 끄는 `user_hidden` 체크 토글 (좌클릭은 네 단계를 순환하므로 서로 다릅니다 — 이 메뉴로 상태를 바꾼 뒤 좌클릭하면 그 상태의 다음 단계로 이어집니다). 좌클릭 동작을 `설정 파일 열기` / `동작 없음` 으로 바꾼 환경에서도 항상 숨김 해제가 가능하도록 제공되는 안전망 — **이 때문에 서브메뉴로 접지 않고 최상위에 둡니다.** 체크 시 인디가 즉시 숨겨지며(트레이 아이콘에서 안쪽 사각형이 사라짐), 해제하면 쓰던 앱을 다시 누르는 순간 나타납니다(메뉴를 쓰는 동안에는 앞에 있는 창이 KoEnVue 자신이라 그 앱을 다시 눌러야 합니다) |
| **커서 헤일로 숨김** | 최상위 — 마우스 커서 주변에 동심원 3개를 띄우는 별도 인디 토글 (기본 ON, 체크 시 숨김). 자세한 내용은 아래 **커서 헤일로** 절 참고 |
| **한/영 배지 ▸ 투명도** | 배지 배경 진하기 3단계 빠른 설정 |
| **한/영 배지 ▸ 크기** | 1~5배 정수 프리셋 + 소수점(예: 2.3배) 직접 입력 |
| **한/영 배지 ▸ 창에 자석처럼 붙이기** | 드래그 중 다른 창 엣지 스냅 켜기/끄기 |
| **한/영 배지 ▸ 전환 강조** | 한/영 전환 시 배지 라벨 강조 on/off (기본 ON) |
| **한/영 배지 ▸ 기본 위치** | 새 앱에서 배지가 처음 뜰 위치 지정 (지금 배지가 붙어 있는 앱의 위치 기준 — 앱별 프로필로 바꾼 경우 포함 — 에 따라 고정/창 기준으로 저장) |
| **한/영 배지 ▸ 위치 기준** | **고정 위치**: 화면 절대 좌표에 고정. **창 기준**: 활성 창의 모서리 기준 상대 위치 — 같은 앱의 창을 여러 개 열어도 각 창에 맞춰 배치 |
| **한/영 배지 ▸ 드래그 활성 키** | 드래그 승격 게이트. **없음** (기본): 임계 초과 시 항상 드래그. **Ctrl / Alt / Ctrl + Alt**: 해당 키를 누른 채 임계 초과 시에만 드래그. 짧은 좌클릭은 항상 일시 숨김(포커스·한/영 변경 시 재표시). 실수로 인디가 끌리는 것을 방지하는 용도 |

| **커서 헤일로 ▸ 전환 강조** | 한/영 전환 시 동심원 스케일 팝 on/off (기본 ON). **"애니메이션 사용"** OFF 시 함께 멈춤 |
| **애니메이션 사용** | 공통 — 배지·커서 페이드/강조/슬라이드 전체 마스터 스위치 (기본 ON). 두 대분류 직후 |
| **시작 프로그램 등록** | 앱 — Windows 로그온 시 자동 시작 (작업 스케줄러 등록) |
| **관리자 권한으로 실행** | 앱 — (v0.9.4.0~) 관리자 권한 cmd / 관리자 Windows Terminal 의 한/영 상태를 표시하기 위한 옵션 (기본 OFF). 켜면 즉시 재시작 여부를 묻고 (YES → UAC 1회 → 관리자 권한으로 자기 재실행) + 시작 프로그램 등록 상태면 자동으로 재등록되어 다음 부팅부터 UAC 없이 관리자 권한으로 자동 시작. UAC 거부 시 안내 다이얼로그 후 일반 권한으로 계속 실행 (관리자 콘솔 한/영 표시는 미작동). 끄면 일반 권한으로 복귀. `koenvue_config.json` 의 `admin_elevation` 키와 동일 |
| **상세 설정...** | 모든 설정을 한 화면에서 편집. 「확인」 은 **바꾼 칸만** 적용합니다 — 창을 열어 둔 동안 `koenvue_config.json` 을 직접 고쳐 저장했다면, 상세 설정에서 건드리지 않은 칸은 파일에서 고친 값이 그대로 유지됩니다 |

> 체크 표시가 있는 항목(숨김·자석·전환 강조·애니메이션·관리자 권한 등)과 투명도는 **메뉴를 열 때 보였던 상태**를 기준으로 적용됩니다 — 메뉴가 열려 있는 동안 설정 파일이 바뀌어도, 체크 항목은 화면에서 본 체크의 반대로, 투명도는 메뉴에 보였던 값으로 바뀝니다.

## 커서 헤일로

마우스 커서 주변에 **동심원 3개 + 흰색 헤일로** 를 띄워 한/영 상태를 커서 옆에서 확인할 수 있는 보조 인디입니다 (메인 라벨 인디와 동시 사용 가능). 기본 ON + 항상 표시 모드 — 첫 부팅부터 마우스 커서를 따라다니며 표시됩니다. 끄려면 트레이 메뉴 **"커서 헤일로 숨김"** 체크박스를 켜면 됩니다.

- **색상** — 안쪽 두 동심원은 현재 IME 색상 (한글 / 영문 / 비한국어 중 하나). 가장 바깥 원은 **CAPS LOCK 이 켜졌을 때만** 보이며, 한/영 상태와 상관없이 **CapsLock 색 (기본 보라)** 으로 그려집니다. 흐릿하게 모드에서는 한/영 색 빛은 안쪽에 그대로 두고 그 바깥에 보라색 띠가 둘러지므로, CAPS 켠 채 한/영을 바꿔도 안쪽 색으로 한/영을, 바깥 보라 띠로 CAPS LOCK 을 따로 읽을 수 있습니다. 색은 상세 설정 「공통 — 색상」의 **「CapsLock 색」** (`caps_lock_color`) 으로 변경 (한/영 배지 CAPS 테두리와 공용)
- **클릭 통과** — 커서 헤일로 위로 마우스 클릭/드래그가 항상 아래 창으로 통과합니다 (선택/스크롤 차단 없음). 한/영 배지와 달리 드래그 이동 / 위치 저장 기능은 없음
- **표시 모드** — 두 가지 (`koenvue_config.json` 의 `cursor_always_show` 키):
  - **항상 표시 (기본)** — 마우스를 따라 계속 위치 추종. 한/영 상태를 시야에서 놓치지 않게 함. 단, 작업 표시줄·바탕화면·시작/검색·클래식 컨텍스트 메뉴 위에서는 커서 헤일로가 숨겨짐. 한/영 배지는 컨텍스트 메뉴·Win11 셸 팝업(빠른 설정 등) 위에서는 함께 숨겨지지만, 마우스가 작업 표시줄·바탕화면·시작/검색 위를 지나갈 때는 그대로 보임 (작업 표시줄이나 바탕화면을 클릭해 포커스가 넘어가면 배지도 숨겨짐). 화면 보호기가 켜져 있는 동안에는 배지·헤일로 모두 숨겨짐
  - **정지 시만 표시** — 마우스 정지 후 100ms 경과하면 인디 표시. 다시 움직이면 즉시 숨김. 작업 중에는 안 보이고 잠시 멈출 때만 확인 가능
- **전환 강조 (기본 ON)** — 한/영을 전환하면 동심원이 잠깐 커졌다 원래 크기로 돌아오는 강조 효과로 변경을 알려줍니다 (한/영 배지의 전환 강조와 같은 동작). 끄려면 트레이 메뉴 **"커서 헤일로 ▸ 전환 강조"** 체크를 해제하세요. 확대 배율·지속 시간은 **상세 설정 → "커서 헤일로 — 전환 효과"** 또는 `koenvue_config.json` 의 `cursor_highlight_scale` / `cursor_highlight_duration_ms` 로 조정. 트레이 메뉴 **"애니메이션 사용"** 을 끄면 이 강조도 함께 멈춥니다 (배지·커서 모든 강조의 마스터 스위치). **정상 동작**: 강조는 **한/영 상태가 실제로 바뀔 때만** 나타납니다. 창만 바꾸는 경우(예: 한글 입력 중인 창 → 다른 한글 입력 창)에는 상태 변화가 없으므로 팝이 뜨지 않습니다 — 버그가 아니라 한/영 배지와 같은 설계입니다.
- **선명도 (기본: 흐릿하게)** — 항상 표시 모드에서 동심원 선명도 3가지. 트레이 **"커서 헤일로 ▸ 선명도"** 또는 상세 설정 Combo · `cursor_display_mode`:
  - **흐릿하게** (`soft`, 기본) — 이동·정지 모두 가우시안 안개 (기본값에서는 고리 대신 커서 둘레의 넓고 은은한 빛 덩어리로 보임)
  - **선명하게** (`sharp`) — 이동·정지 모두 또렷
  - **이동 중 흐릿하게** (`motion`) — 움직일 때만 안개, 멈추면 또렷(기존 PR-29/30)
  - 헤일로 농도/강도: 상세 설정「헤일로 농도」「헤일로 강도」또는 `cursor_motion_alpha` / `cursor_motion_softness` (선명하게 모드에서는 무시·값 보존)
  - 커서 주변 비움 (기본 48px): 흐릿하게 모드(이동 중 흐릿하게는 움직이는 동안)에서 커서 바로 주변은 안개를 비워 글자가 부옇게 보이지 않게 하고, 바깥으로 갈수록 안개가 서서히 나타납니다. 상세 설정「커서 주변 비움 반지름 (px)」또는 `cursor_clear_radius` (0 = 끔, 최대 96). 전환 강조로 커져도 비움 크기는 그대로이며, 선명하게 모드에는 영향 없음. 원이 작거나 헤일로가 얇으면 비움이 자동으로 줄어 헤일로가 사라지지 않음

세밀한 조정 (반지름 / 두께 / 헤일로 불투명도 / 커서 주변 비움 / 전환 강조 / 커서 표시·안개 등) 은 트레이 메뉴 **"상세 설정"** 의 **"커서 헤일로 — 동심원"** / **"커서 헤일로 — 전환 효과"** 섹션 또는 `koenvue_config.json` 의 `cursor_*` 키 직접 편집 ([config-reference.md → 커서 헤일로](config-reference.md#커서-헤일로-cursor-halo) 표 참고) 으로 가능합니다. 저장 즉시 반영됩니다.

## 자주 묻는 질문

**Q. 인디케이터가 어디로 갔는지 안 보여요.**
A. 트레이 아이콘 우클릭 → **한/영 배지** → **기본 위치** → **초기화**를 누르면 기본 위치로 돌아옵니다.

**Q. 특정 앱에서만 인디케이터가 안 떠요.**
A. 전체화면(게임 등)이거나 포커스가 없는 창에서는 자동으로 숨겨집니다. **상세 설정**의 `hide_in_fullscreen`, `hide_when_no_focus`에서 끌 수 있습니다.

**Q. 색상이나 글꼴을 바꾸고 싶어요.**
A. 트레이 → **상세 설정**에서 6개 테마(`custom` / `minimal` / `vivid` / `pastel` / `dark` / `system`) 중 선택하거나 색상 코드(예: `#1A73E8`)를 직접 입력할 수 있습니다. 기본값은 `custom` 이며, 테마를 `custom` 이 아닌 값으로 바꾸면 프리셋 색이 자동 적용됩니다. 프리셋을 쓰다가 `custom` 으로 돌아오면 이전에 설정했던 커스텀 색상이 자동으로 복원됩니다. CAPS LOCK 표시 색 (「CapsLock 색」) 은 테마와 따로 움직여 프리셋을 바꿔도 그대로입니다.

**Q. 설정을 직접 편집하고 싶어요.**
A. exe와 같은 폴더의 `koenvue_config.json`을 텍스트 에디터로 열어 수정 후 저장하면 몇 초(약 5초) 안에 반영됩니다(앱 재시작 불필요). 화면이 잠겨 있는 동안 저장한 편집도 반영됩니다.

**Q. 「설정 파일을 읽지 못해…」 안내가 떠요 / 설정 파일을 고치다 망가뜨렸어요.**
A. JSON 문법 오류(쉼표·따옴표 빠짐 등)나 잘못된 값(예: `"Bold"` 처럼 대소문자가 다른 표기) 때문에 앱이 파일을 읽지 못한 경우입니다.
- **앱을 켤 때** 읽지 못하면 「설정 파일(koenvue_config.json)을 읽지 못해 기본 설정으로 시작했습니다」 안내가 뜹니다. 파일을 고칠 때까지는 기본 설정으로 동작하고, 시작 프로그램 등록 갱신과 업데이트 확인은 파일을 정상으로 읽을 때까지 미룹니다(기본값으로 사용자 설정을 덮지 않도록).
- **실행 중에** 편집하다 읽지 못하면 「설정 파일을 읽지 못해 이전 설정을 그대로 사용합니다」 안내가 한 번 뜨고, 앱은 직전 설정을 그대로 유지합니다. 편집기가 저장하는 순간 파일을 잠깐 잡는 정도로는 안내가 뜨지 않습니다.
- 어느 쪽이든 **파일을 고쳐 저장하면 바로 반영**됩니다.
- 고치기 전에 트레이나 상세 설정에서 설정을 바꾸면 앱이 파일에 씁니다. 이때 **문법이 깨진 파일은 덮어쓰기 전에 `koenvue_config.json.broken` 으로 복사**해 둡니다. 원래 내용을 되살리려면 `.broken` 파일을 메모장으로 열어 오류를 고친 뒤, 그 내용을 `koenvue_config.json` 에 붙여 넣고 저장하세요. (`.broken` 은 가장 최근에 깨진 내용 하나만 보관합니다.) 문법은 맞고 값만 틀린 파일은 앱이 바꾼 항목만 고쳐 쓰고 나머지는 그대로 둡니다.

일부 고급 옵션은 **상세 설정 대화상자에 나오지 않고 `koenvue_config.json` 직접 편집으로만 조작**할 수 있습니다.

| 키 | 설명 | 예시 |
|----|------|------|
| `tray_enabled` | 트레이 아이콘 자체 켜고 끔. 끄고 켜는 것이 **즉시 반영**됩니다. 다만 **OFF 인 동안에는 우클릭 메뉴가 사라지므로 되돌리려면 `koenvue_config.json` 을 직접 편집**해야 합니다 | `false` |
| `user_hidden` | 사용자가 명시 숨김한 상태. 보통은 트레이 좌클릭(좌클릭 동작이 `toggle` 일 때 — 네 단계 순환 중 이 값이 함께 바뀝니다) 또는 우클릭 메뉴 "한/영 배지 숨김"(이 값만) 으로 토글하며, 파일을 직접 편집해서 `true` → `false` 로 바꿔도 해제 (hot reload + 다음 IME/포커스 이벤트 시 복원) | `false` |
| `system_hide_classes_user` | 기본 숨김 목록(바탕화면, 트레이 등) 외에 인디케이터를 숨기고 싶은 **윈도우 클래스명** 추가 목록 | `["MyAppWindow"]` |
| `system_hide_processes_user` | 같은 용도의 **프로세스명** 추가 목록 (확장자 제외, 대소문자 무관) | `["MyTool"]` |
| `app_filter_list` | 특정 앱에서만 인디케이터 표시/숨김할 **프로세스명** 목록 (확장자 제외, 대소문자 무관). 목록의 의미(`"blacklist"` 는 목록 앱에서 숨김, `"whitelist"` 는 목록 앱에서만 표시)는 `app_filter_mode` 로 정하며, 이 모드는 **상세 설정 → 한/영 배지 — 앱별 프로필** 에서도 고를 수 있습니다 | `["notepad"]` |
| `app_profiles` | 특정 앱에서만 일부 설정(색·크기·투명도 등) 오버라이드. 키 형식(`app_profile_match`)은 **상세 설정 → 한/영 배지 — 앱별 프로필** 에서도 고를 수 있습니다. 아래 "앱별 프로필 예시" 참고 | (아래 예시) |
| `advanced.overlay_class_name` | 오버레이 윈도우 클래스명 (내부 디버깅용). 변경 권장하지 않음. 바꾸더라도 **앱을 다시 시작해야 적용**됩니다. 다른 창이 쓰는 이름(`KoEnVue` 로 시작하는 이름, `Button`·`Edit` 같은 시스템 컨트롤 이름, 바탕화면·작업 표시줄 등 셸 창 클래스 이름)은 쓸 수 없어 기본값으로 돌아갑니다 | `"KoEnVueOverlay"` |

**앱별 프로필 예시**

`app_profiles` 는 명시한 앱에서만 일부 설정을 오버라이드하고 나머지는 전역값을 상속합니다. `app_profile_match` 로 키 형식을 선택합니다 — `process` (프로세스명, 기본) / `class` (윈도우 클래스명) / `title` (정규식, 100 ms ReDoS 방어).

`process` 키는 **확장자 없는 소문자 프로세스명**이어야 합니다 — `"notepad"` 는 맞고 `"notepad.exe"`·`"Notepad"` 는 매칭되지 않습니다 (`app_filter_list` 와 달리 대소문자를 구분합니다).

```json
{
  "app_profile_match": "process",
  "app_profiles": {
    "notepad": { "hangul_bg": "#DC2626", "english_bg": "#1D4ED8" },
    "chrome":  { "indicator_scale": 3.0 },
    "devenv":  { "enabled": false }
  }
}
```

notepad 는 한/영 배경색만 바꾸고, chrome 은 크기만 3 배로 키우고, devenv 는 `"enabled": false` 로 **그 앱에서는 한/영 배지를 숨깁니다**.

**Q. 완전히 삭제하려면?**
A. 트레이 → **시작 프로그램 등록** 해제 → **종료** → exe가 들어 있는 폴더 통째로 삭제. 보통은 설정과 로그도 같은 폴더에 있으므로 다른 곳에 흔적이 남지 않습니다. 다만 exe 를 쓰기 권한이 없는 폴더(예: `Program Files`)에 두었다면 설정·로그가 `%LOCALAPPDATA%\KoEnVue\` 에 만들어지므로 그 폴더도 지우세요.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `KoEnVue.exe` | 본체 실행파일 (~5 MB) |
| `koenvue_config.json` | 설정 파일 (자동 생성) |
| `koenvue.log` | 동작 로그 (문제 진단용, 자동 생성) |
| `koenvue.log.old` | 직전 로그 1개 보관본 — 로그가 `log_max_size_mb` 에 닿으면 이 이름으로 밀려납니다 (더 오래된 것은 덮어씀) |
| `koenvue_config.json.broken` | 문법이 깨진 설정 파일의 보관본 — 앱이 읽지 못하는 설정 파일을 덮어쓰기 전에 만듭니다(가장 최근 것 하나). 평소에는 없는 것이 정상이며, 복구 방법은 위 자주 묻는 질문 참고 |
| `koenvue_diagnostics.txt` | 보조 기록 — 관리자 권한 실행을 시도했거나, 일반 로그에 남길 수 없는 이상 종료가 있었을 때만 만들어집니다(평소에는 없는 것이 정상). **파일이 있다고 해서 문제가 생겼다는 뜻은 아닙니다** — 대부분 관리자 권한 시도 기록입니다. 위 두 파일과 달리 `%LOCALAPPDATA%` 로 대체 저장하지 않고 **항상 `KoEnVue.exe` 옆**에만 쓰므로, 쓰기 불가 위치(`Program Files` 등)에서는 아예 생기지 않습니다 |
