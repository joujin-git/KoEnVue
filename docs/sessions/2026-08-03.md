### 왜

- **규범 문서의 일괄 서술은 반례를 의심** — "양쪽에서 토글 가능 + 토글 시 즉시 재등록"에서 앞 절은 참, 뒤 절은 한쪽만 참. 두 문장을 이으면 독자는 전부에 걸린다고 읽는다.

- **`sed -i` 일괄 치환은 줄바꿈까지 바꾼다** — `git status` 98개 중 실제 내용 변경은 48개, 나머지는 LF↔CRLF 라 diff 가 비었다. 개수만 보고 되돌렸으면 정상 작업을 버릴 뻔 — `git diff --stat` 으로 실제 변경량 먼저.
